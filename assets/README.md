# Assets Folder

Replace these placeholder files with your own images and music.

## Required Files

| File | Used In | Description |
|------|---------|-------------|
| `photo1.svg` (or .jpg/.png) | Scene 5 - Photo Memories | First memory photo |
| `photo2.svg` (or .jpg/.png) | Scene 5 - Photo Memories | Second memory photo |
| `photo3.svg` (or .jpg/.png) | Scene 5 - Photo Memories | Third memory photo |
| `photo4.svg` (or .jpg/.png) | Scene 5 - Photo Memories | Fourth memory photo |
| `photo5.svg` (or .jpg/.png) | Scene 5 - Photo Memories | Fifth memory photo |
| `teddy.svg` (or .png) | Scene 7 - Finale | Teddy bear with party hat |
| `bouquet.svg` (or .png) | Scene 2 - Greeting | Rose bouquet illustration |
| `music.mp3` | Background music | Royalty-free soft birthday melody, looping |

## Notes

- When replacing images, update the file paths in the `CONFIG.PHOTOS` array at the top of `script.js`.
- For `teddy` and `bouquet`, update `CONFIG.TEDDY_IMG` and `CONFIG.BOUQUET_IMG` in `script.js`.
- Recommended photo size: 400×500px or similar portrait ratio.
- For music, use any royalty-free `.mp3` file. The site handles autoplay restrictions automatically.
- All SVG placeholders can be replaced with `.jpg`, `.png`, or `.webp` files — just update the paths in `script.js`.
